# CommandCode 管理器
双击安装包安装，桌面快捷方式打开程序。需要 Windows 10/11 64 位；缺少 WebView2 时安装程序会联网安装微软运行组件。
添加账号支持官方网页登录授权、API Key 和本机账号导入。账号工具支持密码保护的账号包导入导出；账号包含登录凭据，只向允许使用账号的人分享。
点击账号查看日、周、月 Token 用量，可指定日期并导出 CSV。界面优先显示本地缓存，后台定时同步。
右下角托盘图标右键查看当前账号额度、刷新和快速切换，双击打开窗口。关闭窗口继续后台监控，右键“彻底退出”停止程序。
程序文件与账号数据分开保存，安装包不含任何账号。覆盖安装和卸载默认保留当前 Windows 用户的账号、备注及用量缓存。
底部“版本号 · 查看更新”打开 GitHub 最新发布页，下载新安装包覆盖安装即可。安装前请从托盘彻底退出旧程序。发布页公开，可直接下载。

分页器旁可选择每页数量，自动模式窗口默认 5 条、最大化默认 6 条；窗口空间不足时自动减少，避免滚动条。拖动窗口边缘调整大小后，顶部可选择恢复默认或保留当前。
