# 本地代理
在工作台顶部打开“本地代理”，勾选支持 API 的 Command Code 账号，点击开启。将面板中的地址和代理 Key 填入其他软件，默认地址为 `http://127.0.0.1:17766/v1`。代理 Key 是工作台生成的本机访问凭据，与平台 API Key 不同。
默认选择当前正常局域网网卡地址，保存后可供同网络的其他设备连接。不会修改 VPN、Windows 系统代理、路由、DNS 或证书。上游请求沿用现有网络环境。适用于桌面或后端 API 客户端，不允许网页跨域访问。
支持模型列表、Chat Completions、Responses 和 Messages；模型必须支持所用接口。账号池支持 Command Code API 套餐及 OpenCode Go / Zen API Key，Command Code Go 不支持 Provider API。
OpenCode Go / Zen 可直接请求官方 API，无需另外启动 OpenCode 或 Node。模型列表中的 `opencode-go/`、`opencode-zen/` 前缀用于区分平台，请保留前缀填写；转发时自动转换为官方模型 ID。同一请求只使用支持同一完整模型名和接口的账号，避免意外跨平台计费。
OpenCode 的公开模型列表不提供协议信息，因此按官方 Go / Zen 文档的接口表校验。当前仅提供已确认支持上述三种接口的模型；原生 Gemini 接口及尚未登记的新模型暂不提供，不自动猜测协议。接口表核实日期：2026-10-14，参考 [Go](https://opencode.ai/docs/go/) 和 [Zen](https://opencode.ai/docs/zen/)。
明确额度不足、限流或凭据失效时自动尝试其他账号，保留同一模型。一般网络故障、权限拒绝或已开始输出的请求不会自动重放。建议关闭调用软件自己的自动重试，避免重复提交。
关闭窗口后可继续托盘运行，彻底退出工作台则代理停止。面板关闭代理会取消正在进行的请求，并要求确认。账号池与 Key 在本机保存，默认关闭；不改变官方客户端登录。
最近 40 条请求记录只保留在内存，显示账号别名、模型、状态和接口返回的 Token，不保存对话正文。重启清空记录，未返回 Token 时显示缺失，不用费用推算。

## 账号池状态与自动换号
账号池以表格展示账号名称、别名、三个周期的可用额度与重置时间。未返回的字段明确显示缺失，刷新读取官方用量；不因打开面板而生成模型请求。
请求优先选择并发较少、已知剩余比例较高的兼容账号，跳过最近 10 分钟同步数据中已确认用尽的账号。旧缓存不长期阻止尝试，过了重置时间允许重新使用。Command Code 仍有额外余额时不会仅因月度额度归零而排除。
上游明确限流时暂时暂停该账号，遵守 Retry-After，到时自动恢复；无等待时间时按短暂等待处理。表格显示暂停原因和恢复时间，逐账号刷新不会跳过速率限制的等待期。
这些机制减少请求开始前的额度错误；已开始输出的回复无法通过更换账号安全续接，所有兼容账号不可用时仍会返回错误。

## 其他设备连接
代理自动选择物理局域网网卡地址，优先选择有网关的网卡，排除常见 VPN / 虚拟网卡，不提供访问范围下拉框。未连接正常局域网时提示检查网络，不退回本机地址冒充内网服务。
复制已保存的地址和启用的代理 Key 到其他设备。工作台须保持运行，网络需可连通，Windows 防火墙须允许访问；软件不自动修改防火墙、端口映射或系统网络设置。
修改端口后显示新地址预览和“待保存”，保存后才更换监听端口；正在进行请求时不能更换端口。
## 安全余量和状态
监控设置中的临界阈值同时用于代理提前换号：默认已用 95% 时保留 5% 安全余量。临界阈值设为 100% 可关闭提前保留，仅在额度用尽时跳过。
“余量不足”表示达到上述阈值，并不等于官方额度已经归零；“额度用尽”表示已确认没有周期余量；“待确认”表示数据过期或接口未返回额度。主列表与账号池保持同一判定。
Command Code 的月度剩余本身不会被当成额外余额。只有已确认的充值 / 免费余额或对应余额差额才作为额外可用额度处理。

## 自动入池与 Key 管理
暂不可用或待确认的账号禁止选择，全选只包含已确认可用账号。启用自动加入后，在正常后台刷新、单账号检测或定时检查中重新判断，额度恢复、凭据有效且没有限流等待时自动加入；不可用时退出。未提供可靠额度的账号不会伪装成已确认可用。
Key 弹窗可管理多个独立 Key，均在工作台以 Windows DPAPI 加密保存。旧版本当前 Key 自动迁移并保持可用；已丢弃的历史 Key 无法恢复。禁用或删除影响后续请求，已认证并开始执行的请求不因 Key 开关而取消。
## 快速使用客户端
开启代理并保存后，选择快速使用中的客户端。自动检测安装位置，从代理获取真实模型列表，按 Chat / Responses / Messages 配置对应协议。每个客户端使用独立 Key，可在弹窗单独停用。
OpenCode 合并全局 JSON 或 JSONC，保留其他服务商与现有设置，将工作台代理设置为默认模型。Command Code 合并 ~/.commandcode/providers.json 和 auth.json，保留原登录，并向受支持桌面版的模型表添加工作台分组；重开后在模型列表选择工作台代理。
已有客户端运行时先询问是否重启；不会因开启代理而自动更改客户端。客户端的项目级设置可能覆盖全局配置，更新 Command Code 版本后可再次快速使用补入模型。
每个配置保留加密的原始备份和最近一次备份，不随点击次数无限增加。格式异常或桌面结构不支持时保留原文件，写入失败则回滚本次修改。
生成的 32k / 4k 限制是保守客户端预算，并非官方模型上限；按需要在客户端调整。
官方配置说明：[Command Code BYOK](https://commandcode.ai/docs/byok)、[OpenCode Config](https://opencode.ai/docs/config/)。
