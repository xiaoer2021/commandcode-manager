# Windows 原生轻量版
双击 `../release-native-v3/CommandCode Manager.exe`。原生 C# 与 Windows .NET Framework 实现，无需 Node.js、Electron 或额外浏览器内核，可执行文件约 85 KB。先从托盘退出旧版再打开本版，各版使用相同加密账号文件。新版加深浅色背景和文字，提高对比，顶部可拖动，切换按钮使用蓝底白字，分页位于右下角。
本版修复授权后本地回调返回 Forbidden：兼容浏览器重定向产生的 Origin: null 表单提交，保留随机 state 校验并拒绝第三方来源。重新发起登录即可，旧登录请求不继续使用。
浅色单屏表格显示账号、套餐、余额、5 小时与每周用量、重置时间、套餐周期和提醒。更多账号分页查看，无横向或纵向滚动条；选择账号后，下方显示余额组成、完整预警与同步异常。
## 登录与切换
“添加账号”支持官方邮箱密码登录和直接添加 API Key。密码输入在系统浏览器的 CommandCode 官方网页；授权完成后自动接收凭据，不保存密码。添加其他账号时，请在官方网页选择对应账号。
“导入本机”读取当前 Windows 用户的 CommandCode 登录账号。切换前验证账号及组织身份，加密备份原配置，再写入 `~/.commandcode/auth.json` 并回读验证。新开的会话生效，已运行的会话请重新打开；环境变量 `COMMAND_CODE_API_KEY` 会覆盖登录文件，其他终端也需检查。
默认每 5 分钟刷新，80% / 95% 用量预警、$5 低余额提醒、套餐周期提前 7 / 3 / 1 天提醒。相同提醒不重复弹出。关闭窗口后托盘继续监控，完全退出请用托盘菜单。
## 占用与数据
本机使用 24 个模拟账号测试，前台约 46 MB、后台约 46 MB，15 秒空闲采样 CPU 使用时间增量为 0；没有发起网络刷新，真实查询和登录时仍有短暂开销。没有账号时不开启监控定时器；隐藏后不重绘；每轮查询完成后只保存和更新一次。
凭据使用 Windows DPAPI 加密，保存于 `%APPDATA%/commandcode-account-manager/accounts-native.json`。旧版 `accounts.json` 保留，本版使用独立文件，可导入本机账号或重新登录添加。切换前原配置备份为同目录 `.native-*.encrypted` 文件，由原 Windows 用户解密。
沿用官方客户端的 `/alpha/whoami?limits=1`、`/alpha/billing/credits`、`/alpha/billing/subscriptions`，主机为 `https://api.commandcode.ai`，按实际 orgId 查询组织数据。未获取字段保持未知，失败保留历史数据并标注异常。购买余额不当作套餐周期到期失效。
真实账号的登录与查询仍需首次接入验证；本机检查使用模拟数据、本地授权回调及隔离临时配置，不修改真实登录文件。
## 构建与检查
执行 `build.ps1`，使用 Windows 自带 C# 编译器构建。
程序参数 `--self-test <输出目录>` 检查加密、未知字段、切换备份、原凭据保留、预警、窗口重置、分页及授权回调，仅使用隔离的测试数据。
`--measure <输出目录>` 使用 24 个模拟账号测量前台及隐藏后的空闲占用，不查询真实账号。
